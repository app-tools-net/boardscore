# 🎲 BoardScore

**BoardScore** is a lightweight, mobile-first, privacy-respecting digital scorekeeper tailored for board games, card games, and tabletop nights. 

No accounts, no tracking, and no clunky app downloads—just a fast, functional web utility designed to replace missing pens and scrap paper straight from your browser.

👉 **Live Utility Tool:** [https://github.io](https://github.io)

---

## ✨ Features

* **Mobile-First Responsive Design:** Large touch targets and an adaptive grid layout optimized for passing a phone or tablet around a crowded table.
* **Real-Time Leaderboard Standings:** Automatically tracks player positions, sorts totals instantly, and highlights the current frontrunner.
* **Round History Ledger:** A dedicated historical breakdown scrolling view so players can double-check logs and prevent scoring mistakes.
* **Privacy-First Processing:** 100% client-side calculation. Your casual gaming data processes locally and never touches an external server.
* **Lightweight & Tracker-Free:** Built using compressed, native web standards for instant loading speeds and minimal data footprints.
